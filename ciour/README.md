# Bundled reference font: TeX Gyre Cursor

`texgyrecursor-regular.otf` (plus italic/bold/bold-italic) is TeX Gyre Cursor,
GUST e-Foundry's actively-maintained metric-compatible clone of URW Nimbus
Mono L, which is itself a clone of the original IBM Courier (designed 1955 by
Howard "Bud" Kettler). It's the font served by the LaTeX Font Catalogue's
"Courier" entry: https://tug.org/FontCatalogue/courier/

We're using this instead of the Microsoft-bundled Courier New because Courier
New itself is a proprietary Monotype font that can't be redistributed --
whereas the shape and the "Courier" name are public domain, and this is a
freely-licensed, redistributable rendering of them.

Downloaded from: https://www.gust.org.pl/projects/e-foundry/tex-gyre/cursor
(package `tg_cursor-otf-2_609-31_03_2026.zip`)
